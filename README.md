# SpeedUp

油猴脚本：为 **Bilibili** 与 **YouTube** 提供更丰富的播放倍速（预设 + 自定义），记忆倍率，并支持长按 O / P 临时变速。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或兼容的用户脚本管理器）
2. 打开管理面板 →「添加新脚本」
3. 将仓库根目录的 [`speedup.user.js`](./speedup.user.js) 全文粘贴保存  
   或使用「从文件安装 / 实用工具 → 导入」
4. 打开 B 站视频页或 YouTube 视频页，刷新后生效

## 功能

| 能力 | 说明 |
|---|---|
| 预设 | `0.5 / 1 / 1.5 / 2 / 2.5 / 3` |
| 自定义 | 输入 `0.1`–`8.0`，回车或失焦生效 |
| 记忆 | 默认按站点分别记忆（B 站 / YouTube） |
| 长按 **P** | 按下 ≥0.5s 后，在当前设定倍速上 ×1.5（十分位四舍五入） |
| 长按 **O** | 按下 ≥0.5s 后，在当前设定倍速上 ×0.5 |
| 松手 | 恢复为已设定的基础倍速 |

实际播放速度通过底层 `video.playbackRate` 设置（可突破站点官方菜单约 2× 的上限）。控制栏上的倍速文字会同步显示**当前有效速度**（含长按期间）。

## 站点差异

- **Bilibili**：原地替换播放器「倍速」菜单内容；并拦截站点把倍速强制拉回 `1×` 的行为（常见于未登录等场景）。
- **YouTube**：官方倍速藏在设置面板里且 API 常卡在约 2×，因此在控制栏右侧注入一个与原生风格一致的倍速按钮 + 菜单；长按 O/P 时该按钮文字会更新。

覆盖范围：YouTube 普通观看 / embed（尽力）；B 站普通视频、多 P、番剧。不覆盖 Shorts、直播。

## 修改记忆方式

编辑脚本顶部 `CONFIG`：

```js
memoryMode: 'per-site', // 默认：分站点记忆
// memoryMode: 'global', // 改成这一行：B 站与 YouTube 共用一个倍率
```

## 已知限制

- 浏览器对 `playbackRate` 大约允许到 16×；本脚本限制在 **0.1–8.0**。
- Chrome 等常在 **&lt;0.5× 或 &gt;4×** 时静音，画面仍可能继续播。
- 站点改版可能导致菜单选择器失效；此时快捷键与 `playbackRate` 仍可能可用。
- 不保证与其它倍速扩展共存。
- 在输入框打字时 O/P 会被忽略；且需按住 0.5s 才触发，减少误触。
